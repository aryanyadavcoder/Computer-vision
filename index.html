Hand Detection using OpenCV & MediaPipe

Real-Time Computer Vision Project using Python

About the Project

This project performs real-time hand detection using Python, OpenCV and MediaPipe. The webcam captures live video frames and MediaPipe detects hand landmarks in real time.

Project Features

  • Real-time webcam video capture
  • Hand landmark detection
  • Hand connection visualization
  • Real-time frame processing
  • BGR to RGB color conversion

Technologies Used

Python OpenCV MediaPipe Computer Vision

How It Works

  1. Webcam captures the video.
  2. OpenCV reads each frame.
  3. The frame is converted from BGR to RGB.
  4. MediaPipe detects hand landmarks.
  5. Landmarks and connections are drawn.
  6. The processed frame is displayed.
